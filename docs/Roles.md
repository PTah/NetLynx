# Роли пользователей NetLynx

В программе три роли. Права **накапливаются**: operator умеет всё, что viewer, admin — всё, что operator.

Обычный вход — страница **«Вход в NetLynx»**. Учётные записи создаёт admin на **Настройки → Пользователи**.

Роль задаётся при создании пользователя. Запасной HTTP Basic из `.env` в браузере больше не сохраняется.

## Кратко

| Роль | Для кого | Суть |
|------|----------|------|
| **viewer** | Наблюдение, дежурство | Смотреть дашборд, узлы, события, топологию, «Обнаружено», **MAC / Петли / Postmortem**. **Ничего не менять.** |
| **operator** | Сетевой инженер | Инвентарь, порты, discovered, ручные связи, уведомления и **действия при инцидентах**, снимки конфига. **Не** пользователи и бэкапы. |
| **admin** | Администратор системы | Всё operator + пользователи, аудит, бэкапы, журнал службы, полная очистка инвентаря. |

## viewer — только просмотр

Можно:

- дашборд, список узлов, карточка (порты, MAC, графики, события, история конфига — чтение);
- лента событий, топология, «Обнаружено»;
- **MAC**, **Петли**, **Postmortem**;
- GET настроек категорий / mac-investigation / inventory preview;
- метрики Prometheus `GET /metrics`.

Нельзя: CRUD узлов, портов, promote, ignore, настройки уведомлений, пользователи, бэкапы, журнал службы.

## operator — работа с сетью

Всё viewer, плюс:

- CRUD узлов (одного), UISP, SNMP-тест, traceroute / tcp-probe;
- порты: admin/PoE/isolate/…, ignore, пороги, **VLAN на порту** (access / trunk allow / remove), **создание / имя / удаление / массовое удаление VLAN** в vlan database (нельзя удалить VLAN, пока он на портах);
- discovered promote/ignore, manual-links;
- sync ролей из show run, ручной config snapshot;
- статус расследования MAC; PATCH mac-investigation;
- **Настройки → Уведомления** (включая incident dry-run / cooldown / admin_down);
- UISP, типы устройств (мутации), очистка stale FDB.

Нельзя: пользователи, audit, бэкапы, «очистить все узлы», журнал службы, удаление оффлайн-пачки (admin).

## admin — система целиком

Всё operator, плюс:

- пользователи и роли;
- журнал аудита;
- резервные копии;
- **журнал службы** (journalctl SSE);
- удалить все узлы / оффлайн-узлы (с `X-Confirm: …`).

Нельзя удалить или понизить **последнего активного admin**.

## Как выбрать роль

- Смотреть — **viewer**.
- Вести сеть и уведомления — **operator**.
- Сервер, люди, бэкапы — **admin**.

## Аварийный admin из `.env`

`NETLYNX_ADMIN_USER` / `NETLYNX_ADMIN_PASSWORD` → HTTP Basic = **admin**. Пароль в браузере не хранится.
