# ELTEX: увеличение MAC aging (FDB)

Этот документ описывает, как увеличить время старения MAC-адресов (aging) на коммутаторах ELTEX серии MES (в том числе MES23xx), чтобы уменьшить частые события NetLynx вида **`UNKNOWN_MAC_ON_ACCESS_PORT`** («Неизвестный MAC») / **`MAC_REMOVED`** («MAC исчез с порта»).

## Что такое aging

`aging-time` — время (в секундах), сколько динамическая запись MAC хранится в таблице FDB без трафика.  
Когда время истекает, MAC удаляется из таблицы. При новом трафике тот же MAC появляется снова.

Из-за этого при длинном интервале опроса FDB в NetLynx можно видеть циклические события:
- `UNKNOWN_MAC_ON_ACCESS_PORT`
- `MAC_REMOVED`
- снова появление MAC на порту

## Рекомендуемое значение

Для старта обычно используют **600-630 секунд** (если это допустимо вашей политикой сети).

## Команды (CLI)

Войти в конфигурационный режим и задать новое значение:

```bash
configure terminal
mac address-table aging-time 600
end
write
```

Пример с максимальным значением (для ряда MES23xx):

```bash
configure terminal
mac address-table aging-time 630
end
write
```

Сброс к значению по умолчанию:

```bash
configure terminal
no mac address-table aging-time
end
write
```

## Проверка

Проверить, что настройка применена:

```bash
show running-config | include aging-time
```

Дополнительно посмотреть таблицу MAC:

```bash
show mac address-table
```

## Важно для NetLynx

Увеличение aging уменьшает шум, но не заменяет корректную роль порта:
- межкоммутаторные/аплинки должны быть отмечены как `trunk` (или `ignore`, если события по ним не нужны);
- клиентские порты — `access`.

Если аплинк помечен как `access`, события по транзитным MAC за соседним коммутатором будут повторяться даже при увеличенном aging.
